# 🎂 生日祝福（st-birthday-wishes）

SillyTavern 扩展：设定你的生日，聊过足够多消息的角色会在你生日当天进入酒馆时，以各自的口吻送上生日祝福卡片。

## 功能

- 设置你自己的生日日期
- 自动统计每个角色的聊天消息数（默认 ≥10 条才算"聊过"，可调）
- 生日当天进入酒馆 → 自动弹出所有聊过角色的祝福卡片，逐个翻页
- 祝福由 AI 按角色的人设和开场白生成，贴合角色口吻（称呼、语气、习惯）
- 每张卡片可**保存为图片**（生日风格卡片 PNG）或**复制文字**
- 祝福按"生日日期+角色"缓存，同一天不重复消耗 API

## 安装

SillyTavern → 扩展 → 安装扩展 → 输入仓库地址：

```
https://github.com/smyz1987/st-birthday-wishes
```

## 使用

1. 右下角悬浮 **🎂** 按钮打开设置面板
2. 设置：生日日期、API（OpenAI 兼容格式：Base URL / API Key / 模型）、消息阈值
3. 点「预览祝福（现在生成）」可以立刻统计并生成一次，确认效果
4. 生日当天进酒馆自动弹出祝福卡片

## 说明

- API 为扩展独立配置，不影响酒馆主配置
- 统计逻辑：直接读取酒馆聊天记录（/api/characters/chats + /api/chats/get），按角色汇总消息数
- 同一天内的统计结果会缓存，不会反复扫描聊天文件
